# Nexus — Criaturas Cósmicas

Frontend do marketplace de NFTs, desenvolvido com React, TypeScript, Vite e
Tailwind CSS.

## Requisitos

- Node.js e npm

## Desenvolvimento

```sh
npm install
npm run dev
```

## Verificações

```sh
npm run typecheck
npm run lint
npm run build
```

O TypeScript está habilitado em `src/` pelo `tsconfig.json`. Componentes React
devem usar a extensão `.tsx`; arquivos TypeScript sem JSX devem usar `.ts`.
O build executa a verificação de tipos antes de gerar os arquivos de produção.
